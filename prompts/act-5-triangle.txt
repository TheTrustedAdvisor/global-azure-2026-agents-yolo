team 3:
  fabric-documenter: Nutze OMG's document-specialist Agent. Enumeriere via 'az rest --method get --url "https://api.fabric.microsoft.com/v1/workspaces" --resource "https://api.fabric.microsoft.com"' alle Fabric-Workspaces. Filtere auf Praefix 'mf-' und waehle den ersten Treffer. Fuer diesen Workspace liste alle Items via '/workspaces/{id}/items' und erstelle eine vollstaendige Dokumentation: Struktur, Items (Typ, Name, Owner), Purpose, architektonische Observations, Empfehlungen. Output als gut lesbares Markdown nach docs/fabric-workspace-doc.md.

  m365-security-reviewer: Nutze OMG's security-reviewer Agent. Fuehre ein Security-Review meines M365-Profils via Graph API durch. Calls: 'az rest --url https://graph.microsoft.com/v1.0/me', '.../me/authentication/methods', '.../me/appRoleAssignments'. Bewerte: MFA-Status, Authentication-Methods-Vielfalt, zugewiesene Rollen, Privileged Access, mittelbare Risiken. Priorisierte Findings und konkrete Empfehlungen. Output nach docs/m365-security-review.md.

  azure-architect-critic: Nutze OMG's architect Agent. Liste Azure Resource Groups via 'az group list' und waehle die erste mit Praefix 'rg-' oder die vom User referenzierte. Hole Details zu allen Ressourcen via 'az resource list --resource-group {name}'. Kritisiere die Architektur: Ressourcen-Komposition, Naming-Conventions, Tagging-Strategie, Region-Wahl, Kosten-Bewusstsein, Security-Posture, Missing Best Practices. Output nach docs/azure-rg-architecture-review.md mit Severity-Level pro Finding (Critical/High/Medium/Low).
